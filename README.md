# TUDT-F: Trust-Gated Smart-Energy Digital Twin

This repository contains a reproducible implementation of TUDT-F, a trustworthy uncertainty-aware digital twin framework for smart-energy decision support. The framework combines:

- semantic twin-state representation,
- random-forest load and renewable forecasting,
- conformal prediction intervals,
- pandapower feasibility checks,
- synchronization, data-reliability, uncertainty, and anomaly evidence,
- trust-gated recommendation, cautious scaling, and abstention.

The implementation uses public Open Power System Data (OPSD) time-series measurements and scales regional load, renewable generation, and price signals into a microgrid-equivalent testbed.

## Repository Structure

```text
src/
  tudtf_core.py                  Core data preparation, forecasting, trust scoring, and primary experiment
scripts/
  run_rolling_validation.py      Rolling monthly validation and statistical tests
  run_extended_analysis.py       Decoupled metrics, auxiliary gates, threshold sensitivity, DK_1 check
  run_control_and_runtime.py     OPF-like constrained dispatch baselines and runtime measurements
  run_all.py                     Runs the complete pipeline
data/
  processed/                     Derived microgrid-scale data
  raw/                           Raw OPSD download location, ignored by git
results/
  primary/                       Primary experiment tables and figures
  rolling_validation/            Rolling-window validation tables
  extended/                      Metric-separated, sensitivity, external-region, and control-baseline tables
  figures/                       Main result figures
```

## Installation

Python 3.10 or newer is recommended.

```bash
python -m venv .venv
.venv\Scripts\activate
python -m pip install --upgrade pip
python -m pip install -r requirements.txt
```

On Linux or macOS, use:

```bash
source .venv/bin/activate
```

## Data

The code uses the OPSD time-series package, version `2020-10-06`:

https://data.open-power-system-data.org/time_series/

The raw file is downloaded automatically to `data/raw/opsd_time_series_60min_singleindex.csv` if it is not already present. The raw file is not tracked because it is large. A derived microgrid-scale CSV is included in `data/processed/` for convenience and can be regenerated by running the core script.

## Run

Run the complete pipeline:

```bash
python scripts/run_all.py
```

Run individual stages:

```bash
python src/tudtf_core.py
python scripts/run_rolling_validation.py
python scripts/run_extended_analysis.py
python scripts/run_control_and_runtime.py
```

For a shorter smoke run of the primary experiment:

```bash
python src/tudtf_core.py --max-test-rows 48
```

## Reproducibility Notes

The experiments use fixed random seeds for scenario injection and model training. The trust-score weights, trust thresholds, battery parameters, feeder parameters, and scenario-injection settings are defined directly in the scripts. The same settings are used across DE-LU and DK_1 validation.
