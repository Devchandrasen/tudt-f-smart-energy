# Changelog

## 2.0.0

- Adds causal forecasting and evidence-driven dispatch on IEEE 33 and SimBench MV.
- Includes a full 62,208-record experiment, independent physical labels and model/plant separation.
- Adds a Python package, command interface, pinned dependencies and protected reference data.
- Includes complete manuscript sources, figures and mathematical definitions.
- Documents cost, violation and selective-risk trade-offs with block-level uncertainty.
- Adds data provenance, numerical checks, tests and continuous integration.
